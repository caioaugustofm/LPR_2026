## Sobre o Repositório

Este repositório reúne os exercícios, atividades e projetos desenvolvidos ao longo da disciplina. Seu objetivo é documentar o aprendizado, registrar a evolução dos conteúdos estudados e servir como material de consulta para revisões futuras.

* Desenvolver a lógica de programação.
