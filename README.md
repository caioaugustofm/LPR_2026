## Sobre o Repositório

Este repositório reúne os exercícios e atividades desenvolvidos durante as aulas de Linguagem de Programação.

Seu objetivo é:

* Registrar o aprendizado ao longo da disciplina;
* Organizar os conteúdos estudados;
* Servir como material de consulta para revisões futuras;
* Documentar a evolução das habilidades em programação;
* Praticar versionamento utilizando Git e GitHub.
